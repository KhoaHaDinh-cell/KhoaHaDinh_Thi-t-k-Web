# Portfolio cá nhân – Hà Đình Khoa

## 1. Giới thiệu
Đây là dự án Portfolio cá nhân phục vụ môn FIT4014 – Thiết kế Web.
Website giới thiệu thông tin cá nhân, kỹ năng, dự án học tập,
lộ trình học tập và biểu mẫu liên hệ.

## 2. Công nghệ sử dụng
- HTML5
- CSS3
- Responsive Web Design

## 3. Nội dung website
- Giới thiệu cá nhân.
- Kỹ năng HTML5, CSS3 và Responsive.
- Các dự án học tập.
- Lộ trình học tập.
- Biểu mẫu liên hệ mô phỏng.

Lưu ý: Biểu mẫu liên hệ hiện chưa gửi email hoặc lưu dữ liệu vào cơ sở dữ liệu.

## 4. Cấu trúc dự án

- index.html: Trang Portfolio chính.
- style.css: Định dạng giao diện.
- ket-qua.html: Trang kết quả biểu mẫu.
- kiem-tra-lab5.txt: Tài liệu kiểm tra Lab 5.
- CHANGELOG.md: Nhật ký thay đổi.
- AI_LOG.md: Nhật ký sử dụng AI.
- docs/: Tài liệu và minh chứng Lab 8.

## 5. Cách chạy dự án
1. Tải hoặc clone repository về máy.
2. Mở thư mục dự án bằng Visual Studio Code.
3. Mở file index.html bằng trình duyệt web.
